# 写实微缩设计系统

风格由材质、人物和工作关系共同建立。暖灰页面与场景背景衔接，石墨文字提供阅读对比，灰蓝和鼠尾草绿用于少量强调。标题、正文、流程、表格和图表采用同一主题；写实纹理只用于配图，页面信息区使用干净的实色表面。

## 色彩与字阶

| 用途 | 令牌／颜色 |
|---|---|
| 页面纸底、配图背景 | `--paper: #EEEDE8` |
| 标题、正文重点 | `--ink: #26313A` 石墨 |
| 主要强调、语义图标 | `--blue: #55748A` 灰蓝 |
| 正文辅助 | `--muted: #5F6666` |
| 细线、分隔 | `--line: #CFD1C9` |
| 信息分组浅底 | `--panel: #E3E4DC` |
| 图表辅助、流程关系 | `--diagram-accent: #798469` 鼠尾草绿 |
| 少量状态、细线 | `#B88A43` 赭黄，实色而非金属 |

图表第三色使用 `--chart-tertiary: #B88A43`，网格使用 `--chart-grid: #CFD1C9`，避免继承其他主题的默认强调色。

画布 1920 × 1080。沿用共享布局的页头页脚、内容安全区和正文尺度；普通标题 46px，副标题 25px，封面主标题约 80px，尾页约 96px，页码 40px。阅读型组件使用共享可读字号，不靠缩小字号提高密度。中文用系统可用的无衬线字体，不依赖远程字体。

## 强调与组件

- 同层级说明保持相同左边界、间距与正文大小。轻量重点使用 `emphasis: true`：标题与图标约放大 10%，加字重和灰蓝短线。不要给单独一个同级条目突然加厚框、阴影或大色块。
- 真正分组才使用 `presentation: "panel"`；底板为暖灰实色、1px 细边、6px 圆角，无玻璃透光或浮起阴影。状态用标签，解释用开放式排版。
- 表头石墨底、暖白字；交替行是轻微实色差。图表继承灰蓝／鼠尾草绿，保留轴、来源与相邻解释，不能把低对比辅助色用于小字正文。
- 封面和尾页保持开放、场景主导；不将整个页面做成拟物办公室，不让木纹、墙纸或地板铺满文字区。

## 场景与构图

查看 `../assets/reference-design/approved-workflow.png`（用户确认的无文字方向）和 `review-scene.png`（协作近景）。保持 35–45° 等距观感、抬高基座、真实 PBR 材质、柔和聚焦灯光。常见材质是浅橡木、粉末涂层金属、织物、矿物复合材料。人物需要五官细节、明确表情、自然手部与衣物褶皱；不要退回无脸白色人偶。

场景可表达计划、执行、跟踪、复盘等工作，也可按大纲换成具体业务的设备、服务或流程。人物数量、分区数量、路径及道具由本页决定。参考中的四区闭环与顶部勾选图形不属于强制模板。标题、系统名、字幕、标签和数值全部留在可编辑 HTML；配图为无文字版。

阅读型先按主体分区安排配图：`half_lr / half_tb / half_diagonal` 占 1/2，`quarter` 占 1/4。比例不含页头页脚及全宽摘要。多图应有不同视角或内容，不能在同页复制同一张图。其余区域组合图表、矩阵、流程及说明；超量拆页。图有完整基座和阴影，按实际可见本体检查大小，不能用大量留白充配图面积。

## 样例的使用边界

两份 JSON 模板有逐图简报，但不捆绑已填充的业务图片路径；制作时生成或映射实际素材。包内两张参考用于确认材质及验证布局，验证预览可以跨页复用并说明；真实成稿应逐页核对语义，不把有限样例当作全稿图库。示意图表不提供真实证据，业务数字与产品能力须来自用户资料。

## 阅读型控制区与架构标注

窄栏长文字采用标签在上、说明在下的排列，校验要求和异常处理分开；短标签、相同语义的行保持一致的缩进和节奏。强调用浅色标签和细分隔，不将所有说明加框。

架构按 `layer/module/source/governance/flow` 分工：层级的编号与名称最醒目，模块名称清晰稳定，治理与流向用灰蓝／鼠尾草绿和短引线识别。需要双层文字时用 `prefix/detail`，方向用 `direction`；先为标注分配足够空间再定图像尺寸，修改后逐一核对。字段见共享 [架构版式](../../white-blue-slides/references/deck-format.md#architecture与模型对齐的直接标注)。
