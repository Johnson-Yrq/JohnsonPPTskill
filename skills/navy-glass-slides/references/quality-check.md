# 海蓝玻璃演示稿验收

先按已确认的[演讲型或阅读型用途](../../white-blue-slides/references/presentation-modes.md)决定信息密度。下文关于大场景主导、少量说明的常规版式要求适用于演讲型；阅读型按主体版面分区选择 1/2 左右、1/2 上下、1/2 对角双图或 1/4 配图；主体版面不含页头页脚及全宽摘要。先确定配图分区，再用图表、图标、矩阵和文字组织其余内容。有可靠数量数据时可使用 ECharts；不得缩小字号、重复插图或补造指标，放不下则拆页。阅读型内容不可仅放在讲稿中，也不可通过整体缩小来增加密度。

先看整稿节奏，再逐页查看实际渲染。程序只能验证结构与部分外观，不能替代业务关系、材质、图文对位的判断。

## 风格与内容

- 根 `style` 为 `saas-3d`；封面、页头、信息块、图标、流程、表格及尾页使用本风格主题。暖白底 `#F7F6F2`、海军蓝标题 `#1D3446`、灰青图标与辅助强调 `#477F80`、少量金色细节 `#BC9B59` 形成一致层级，不能只替换配图而沿用旧主蓝页面；品牌 Logo 自有颜色不受此限制。
- 对照 [设计系统](design-system.md) 与已确认配图，检查精细倒角、薄设备、微缩尺度、建筑前后层次、透明玻璃边缘与克制金属细节。不能出现厚黏土设备、过大的小人、大片青绿或密集包金装饰。
- 有主要显示屏时，深海军蓝界面在清透玻璃外缘之内；界面为细密的屏幕平面结构。没有软件屏的页面仍保持同样材质与视觉层级，不为套风格强行补屏幕。
- 结论、对象、操作、层级和因果对应原大纲；参考图的名称、金额和示例图表未成为业务事实。概念 UI 与真实截图区分清楚。
- `ui_text: none` 没有文字或乱码；`demo` 只含许可的短屏幕标签。页面标题、模块名、解释与真实数据均为可编辑节点。

## 排版与场景

- 场景本体充分占据图框，主对象及完整底座都在画幅内；最前方底角、玻璃外缘、屏幕和关键流程节点不被裁切。
- 上图下文主体横向铺开并与各列说明对位；自动检查 `image_balance` 达标后，仍需看实际可见物体是否够大。
- 标题、正文、标签无重叠、出界、孤立标题或不合理换行；不靠缩小字号和图片容纳过多文字。
- 架构的每个层级、模块及连接按大纲映射，HTML 文字直接靠近对应对象；不使用遮挡面板掩盖错误层级或图中文字。
- 面板用于真实分组，普通说明使用留白与分隔。语义图标、状态标签、深浅分组及条目数量符合 `visual.requirements`；不能隐藏图标或透明化底板骗过契约。
- 同层级说明的强调保留条目缩进、正文大小与间距，不出现孤立的选中态卡片；标题与图标略微放大后没有碰撞或不合理换行，仍能连续阅读相邻内容。
- 阅读型分区：同一行的模块标题顶边一致；标题下方的内容以及配图与说明在各自分区内上下留白相等，不顶到标题下方而在底部留空（审查器 `reading-heading-not-top` / `reading-region-not-centered`）。
- 图片边缘融入纸底，保留玻璃透光、深色显示面和柔和投影；无整体变暗的矩形、突兀光斑或强行淡出造成的主体缺损。

逐页记录关键观察及修复，例如“第 3 页四个处理节点与四列说明对应，右端输出完整；第 5 页三层九模块的标注贴近实际对象，玻璃通路未遮住文字”。不能复制“无溢出、通过”代替实际看图。

## 文件与功能

- CSS、JS、图片、Logo 与图标内嵌；离线打开无 CDN 或旁边素材目录依赖。
- 页数、页码、总览、End 键及末页状态一致；翻页、讲稿、总览跳转、编辑、全屏、另存和打印可用。
- 修改文字、另存并重新打开后，文字和图片仍在；打印每页一张 16:9，无额外空白页。
- 成稿没有缺图占位、草稿标识、未完成文本、假二维码或虚构联系信息。

## 共享检查器

先运行 `build_deck.py --check-plan`，检查设计理由、显式要求、图标选择、结构字段、架构坐标及 Logo 资源。它不需要图片已存在，不能根据最终 HTML 倒推一份容易通过的要求。

图片齐全后构建并运行 `audit_deck.cjs`。审查器通过独立本地浏览器检查技术功能、设计契约与当前主题；`brandOK` 应按 `saas-3d` 主题变量检查，不能用旧风格颜色或样式要求判断新稿。逐项处理报告中的 `manualReview` 和警告；缺少 Playwright 时用允许的浏览器等价检查并明确范围，不宣称自动检查全部通过。

结构与技术检查通过后，仍要实际查看逐页截图，尤其封面、架构、长标题和高密度页面。修改 Skill 脚本或主题后运行共享 `selftest.py`，再检查一份使用本风格真实配图的 HTML；最终交付成稿链接，预览和报告可附，不能把过程文件作为用户打开演示稿的依赖。
